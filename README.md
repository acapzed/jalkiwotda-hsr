# 한눈에 이잘키 정오표 / jalkiwotda-hsr

HoYoLAB 스타레일 전적 페이지에서 캐릭터 정보를 읽어, 커뮤니티 기준표 **"이정도면 잘키웠다"** 와 비교하는 브라우저 확장 프로그램입니다.

> 이 프로젝트는 HoYoverse 공식 프로젝트가 아닌 팬 메이드 도구입니다.

---

## 주요 기능

- HoYoLAB 스타레일 전적 페이지에서 캐릭터 데이터 캡처
- 여러 캐릭터를 한 번에 분석
- "이정도면 잘키웠다" 구글 스프레드시트 기준과 비교
- 광추, 유물/장신구 세트, 주 옵션, 주요 스탯 목표 표시
- 브라우저 안에서 HTML 리포트 생성
- 별도 서버 없이 로컬 브라우저에서 동작

---

## 설치

현재 Chrome Web Store에는 등록되어 있지 않습니다. 개발자 모드로 직접 불러와서 사용하세요.

**Chrome / Edge 공통**

1. 이 저장소를 내려받거나 압축을 풉니다.
   - 패키징된 ZIP을 사용하려면 `dist/jalkiwotda-hsr.zip`을 압축 해제하세요.
2. 브라우저 확장 프로그램 관리 페이지를 엽니다.
   - Chrome: `chrome://extensions`
   - Edge: `edge://extensions`
3. 오른쪽 위의 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드**를 클릭합니다.
5. `manifest.json`이 있는 저장소 루트 폴더를 선택합니다.
6. 목록에 `jalkiwotda-hsr`가 표시되면 설치 완료입니다.

## 사용법

1. 확장 프로그램을 설치한 브라우저에서 HoYoLAB에 로그인합니다.
2. HoYoLAB 언어를 **한국어**로 설정합니다.
3. 스타레일 전적 페이지로 이동합니다.
4. 페이지를 새로고침합니다.
5. 화면 오른쪽 아래에 패널이 나타납니다.
6. HoYoLAB이 캐릭터 정보를 로드하면 **불러온 정보** 숫자가 올라갑니다.
7. **정오표 보기** 버튼을 누르면 분석 리포트가 표시됩니다.

> **참고** — HoYoLAB 언어가 한국어가 아니면 캐릭터 이름·스탯명이 매칭되지 않습니다. 이 경우 확장 프로그램이 언어 변경 안내를 표시합니다.

### 패널 버튼

| 버튼 | 설명 |
|------|------|
| 정오표 보기 | 현재 캡처된 캐릭터 정보를 기준표와 비교해 리포트를 엽니다 |
| 새로고침 | 캡처 데이터를 초기화하고 HoYoLAB 페이지를 새로고침합니다 |

## 리포트 항목

| 항목 | 내용 |
|------|------|
| 캐릭터 | HoYoLAB에서 읽은 캐릭터 이름 |
| 레벨 | 캐릭터 레벨 및 성혼 |
| 역할 | 기준표의 역할 구분 |
| 광추 | 장착 광추와 추천 광추 비교 |
| 세트 | 유물/장신구 세트 비교 |
| 주 옵션 | 몸통·신발·구체·매듭 주 옵션 비교 |
| 스탯 목표 | 기준표의 주요 스탯 목표와 현재 스탯 비교 |
| 치명타 목표 | 치명타 관련 목표와 현재 스탯 비교 |
| 현재 스탯 | 현재 캐릭터 표시 스탯 요약 |

**표시 상태**

- `적합` — 기준에 맞거나 허용 범위로 판단됨
- `확인` — 기준과 맞지 않는 것으로 판단됨
- `?` — 데이터가 없거나 자동 판단이 어려움

## 데이터 및 권한

이 확장 프로그램이 사용하는 데이터는 다음과 같습니다.

- HoYoLAB 페이지가 브라우저에서 로드한 스타레일 캐릭터 응답
- 공개 구글 스프레드시트 CSV 기준표
- HoYoWiki의 유물/장신구 세트 이름 정보

로그인 토큰이나 비밀번호를 수집하지 않으며, 모든 분석은 사용자의 브라우저 안에서 처리됩니다. 외부 서버로 데이터를 전송하지 않습니다.

브라우저 권한에는 기준표를 가져오기 위한 `docs.google.com` 및 Google user content 도메인 접근이 포함됩니다.

## 문제 해결

**패널이 보이지 않을 때**
- 올바른 HoYoLAB 스타레일 전적 페이지인지 확인하세요.
- 확장 프로그램 설치 후 페이지를 새로고침하세요.
- `chrome://extensions`에서 확장 프로그램이 활성화되어 있는지 확인하세요.

**"불러온 정보"가 계속 0일 때**
- HoYoLAB에 로그인되어 있는지 확인하세요.
- 캐릭터 정보가 완전히 로드될 때까지 기다린 후 다시 확인하세요.
- 페이지를 새로고침하고 재시도하세요.

**리포트가 뜨지 않고 "아직 캐릭터 정보를 가져오지 못했습니다"가 표시될 때**
- HoYoLAB 페이지를 새로고침한 뒤 캐릭터 정보가 완전히 로드될 때까지 기다렸다가 **정오표 보기**를 다시 눌러보세요.

**기준표와 매칭이 안 될 때**
- 개척자, March 7th처럼 운명의 길에 따라 이름이 달라지는 캐릭터는 자동 매칭이 제한될 수 있습니다.
- HoYoLAB 데이터 구조나 기준표 표기가 변경된 경우 일부 항목이 `매칭 없음` 또는 `?`로 표시될 수 있습니다.

**유물/장신구 세트가 "매핑되지 않은 세트"로 표시될 때**
- HoYoWiki 또는 내부 매핑에 아직 반영되지 않은 신규 세트일 수 있습니다.
- 게임 업데이트 직후에는 세트 이름 매칭이 일시적으로 실패할 수 있습니다.

## 현재 한계

- HoYoLAB 페이지 구조나 API 응답 형식이 변경되면 동작하지 않을 수 있습니다.
- 기준표의 셀 구조가 크게 바뀌면 파싱이 실패할 수 있습니다.
- 자동 비교는 기준표 문구와 HoYoLAB 표기를 정규화하여 매칭하는 방식으로, 모든 케이스를 완벽하게 판단하지는 못합니다.
- 현재 리포트 UI는 검증 목적의 간단한 HTML 테이블 형태입니다.
